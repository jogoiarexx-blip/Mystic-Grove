Como jogar

Mire e lance sementes elementais. Junte 3 ou mais do mesmo elemento para liberar energia.

Reações especiais: água fortalece brotos, fogo queima cipós, vento empurra grupos e pedra quebra cascas resistentes.

Peças sem sustentação caem e viram bônus. Correnteza, vento, armaduras, totems, chefes e habilidades dos guardiões alteram o tabuleiro.

Mouse/toque: arraste para mirar e solte para disparar.

Teclado: ← → para mirar, Espaço para disparar, Q para a habilidade e Esc para pausar.
